В первом приближении алгоритм QuickSort выглядит так:
1. С помощью какого-нибудь алгоритма выбираем опорный элемент (pivot)
2. Переносим все элементы меньше pivot влево, в все больше – вправо (это называется partition).
3. Запускаемся рекурсивно от левой и правой части.

Если выбирать pivot случайно, то мат. ожидание времени работы быстрой сортировки равно $O(n\log{n})$. Если хотим детерминированное $O(n\log{n})$, то выбирать pivot нужно равным [[Алгоритм медианы медиан|медиане медиан]].
## Partition
Существует две схемы partition: разбиение Ламуто и схема Хоара.
## Разбиение Ламуто
Будем поддерживать префикс с элементами меньше опорного и проходится по массиву слева направо. Если встретим элемент меньше опорного, делаем swap с элементом префикса и увеличиваем длину префикса на 1. В конце меняем последний элемент префикса с pivot.

```
algorithm partition(A, low, high) is
    pivot := A[high]
    i := low
    for j := low to high do
        if A[j] ≤ pivot then
            swap A[i] with A[j]
            i := i + 1
    swap A[i] with A[high]
    return i
```

Работает менее эффективно, чем схема Хоара. В случае уже отсортированного массива или равенства всех элементов, сложность сортировки возрастает до $O(n^2)$.
## Схема Хоара
Заведем два индекса (один в начале массива, другой – в конце), которые будут приближаться друг к другу, пока не найдется пара элементов, где один больше опорного и расположен перед ним, а другой меньше опорного и расположен после него (иными словами, эти два элемента образуют инверсию с опорным элементом). Эти элементы меняются местами и алгоритм продолжается дальше, пока индексы не пересекутся.

```
algorithm partition(A, low, high) is
   pivot:= A[(low + high) / 2]
   i:= low
   j:= high
   while i < j
       while A[i] < pivot 
              i:= i + 1
       while A[j] > pivot
              j:= j - 1
       if i >= j then
           return j
       swap A[i] with A[j]
       i++
       j--
```
