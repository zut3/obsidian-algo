**Задача**. Хотим найти все простые на отрезке от $1$ до $n$.
Будем перебирать числа от 2 до $n$ и помечать, какое простое, а какое – нет.  Если число простое, давайте пометим все числа, кратные ему, как составные. Если число составное, пропустим его и перейдем к следующему.
```cpp
for(int i = 2; i <= n; i++) {
	if(!is_prime[i]) continue;
	for(int j = 2*i; j <= n; j += i) {
		is_prime[j] = false;
	}
}
// В массиве is_prime изначально все элементы true
```
Утверждается, что такое работает за $O(n\log{\log{n}})$
## Линейное решето
Давайте, вместо просто bool, считать для каждого числа его минимальный простой делитель. Обозначим этот массив за `d[k]`. Помимо этого, будем поддерживать список $p$ всех найденных простых чисел на текущий момент.

Будем перебирать число $k$ от $2$ до $n$. Если это число простое, то положим его в список $p$. Далее, заполним массив $d$. Ясно, что для всех простых меньше $d_{k}$ верно `d[k * p[i]] = p[i]`. 

```cpp
for(int k = 2; k <= n; k++) {
	if(d[k] == k) {
		p.push_back(k);
	}
	for(int x : p) {
		if(d[k] >= x) d[k * x] = x;
	}
}
```
Такое уже работает за $O(n)$.
