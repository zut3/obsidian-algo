Бинарное дерево, которое обладает следующим свойством: если узел дерева имеет ключ $k$, то все узлы в левом поддереве имеют ключи строго меньше $k$, а все узлы в правом поддереве имеют ключи больше $k$.
## Операции
### Find
Найти узел в дереве, имеющий ключ $k$. 
Пойдем от корня вниз. Если текущая вершина $x$ имеет ключ $k'$, то:
1. $k' = k$. $x$ – искомая вершина
2. $k' > k$. Идем в левое поддерево.
3. $k' < k$. Идем в правое поддерево.
Работает за $O(h)$, где $h$ – высота дерева.
### Insert
Операция вставки работает аналогично поиску элемента, только при обнаружении у элемента отсутствия ребенка нужно подвесить на него вставляемый элемент.
```
Node insert(x : Node, z : T):               
	if x == null 
	    return Node(z)                        
	else if z < x.key
	    x.left = insert(x.left, z)
	else if z > x.key
	    x.right = insert(x.right, z)
	return x
```
## Remove
Рассмотрим 3 случая:
1. Удаляемая вершина – **лист**. Можем безболезненно ее удалить.
2. У удаляемой вершины **один ребенок**. Подвесим ребенка к нашему родителю.
3. У удаляемой вершины **два ребенка**. Находим минимальный элемент в правом поддереве (или максимальный в левом). У него не будет левого ребенка. Удаляем его по правилу пункта 2 и вставляем на место удаляемой вершины.
## Lower Bound
Найти узел с наименьшим ключом $k$, который больше или равен $x$.
Спускаемся от корня вниз:
1. Если у текущей вершины ключ равен $k$, то мы нашли точное совпадение. Возвращаем $k$
2. Если у текущей вершины ключ больше $k$, запоминаем его как потенциальный ответ. Идем в левое поддерево.
3. Если у текущей вершины ключ меньше $k$. Такой ключ нам не подходит. Идем в правое поддерево.
## Поиск k-порядковой статистики
Подсчитаем для каждой вершины $S(x)$ – размер поддерева вершины $x$.
Тогда можем найти $k$-порядковую статистику [[Поиск порядковой статистики|тем же алгоритмом]], что и на массиве. Сложность $O(h)$.
